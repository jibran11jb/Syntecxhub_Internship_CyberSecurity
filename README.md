# Syntecxhub Cybersecurity Internship

Hands-on cybersecurity projects built during my cybersecurity internship at **Syntecxhub** (about one month, 2026). Each task was assigned by the company and implemented by me, covering network security, cryptography, secure communication, and vulnerability assessment.

## Projects

| # | Project | What it does |
|---|---------|--------------|
| 1 | **Port Scanner** | Scans a target host to discover open ports and running services. |
| 2 | **Password Manager** | Stores and retrieves credentials securely instead of keeping them in plain text. |
| 3 | **Encrypted Chat App** | Client-server chat where messages are encrypted in transit. |
| 4 | **Encrypted Android Chat** | Mobile version of the encrypted chat for Android devices. |
| 5 | **SQL Injection Scanner** | Tests web inputs for SQL injection vulnerabilities and reports findings. |
| 6 | **CVE Scanner** | Checks software or services against known CVE vulnerabilities. |
| 7 | **Secure File Transfer** | Transfers files between machines with encryption to protect data in transit. |

## Skills Demonstrated

- Network programming and socket communication
- Applied cryptography (encryption, secure storage of secrets)
- Web application vulnerability testing
- Vulnerability identification using CVE data
- Secure client-server and mobile app design

## Getting Started

```bash
git clone https://github.com/jibran11jb/Syntecxhub_Internship_CyberSecurity.git
cd Syntecxhub_Internship_CyberSecurity
```

Each project lives in its own folder. Open the folder of the project you want to run and check its source files for usage details.
